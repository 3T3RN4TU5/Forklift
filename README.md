# VoltLift (first version)

The first version of the VoltLift electric forklift website, with a rotating 3D forklift, services, fleet and contact sections. The newer version lives in [Electric-Forklift](https://github.com/3T3RN4TU5/Electric-Forklift).

**Live:** https://forklift-ivory.vercel.app

![VoltLift hero beside an interactive 3D forklift](docs/screenshot.jpg)

![Animated demo: scrolling through the VoltLift site](docs/demo.gif)

## Built with

A single `index.html` with HTML, CSS, JavaScript and Three.js (from a CDN).

## Run it locally

Open `index.html` in a browser.
